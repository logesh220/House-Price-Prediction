# House Price Prediction

## Project Overview
This project predicts house prices in Indian cities using Machine Learning.
It uses property details such as city, property type, area, number of bedrooms,
bathrooms, property age, and other features to estimate the price.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Streamlit
- Git and GitHub

## Machine Learning Models
- Linear Regression
- Random Forest Regressor

## Features
- Predict house prices based on property details.
- Compare machine learning models.
- Visualize house price distributions and feature importance.
- Explore housing data through charts.

## How to Run the Project

1. Clone this repository.
2. Install the required dependencies.
3. Obtain the dataset separately and place it in the appropriate folder.
4. Train the model using the training script.
5. Run the Streamlit application.

Install dependencies:

    pip install -r requirements.txt

Train the model:

    python train_model.py

Run the application:

    streamlit run app.py

## Dataset
The dataset is not included in this repository.
Obtain it from the original Kaggle competition and follow its terms of use.

## Disclaimer
This project is intended for educational purposes.
Predictions are estimates and should not be treated as official property valuations.
